# Sistema de IA

Proyecto de práctica para la materia Arquitectura de Sistemas de Inteligencia Artificial.

## Descripción

Este proyecto simula el desarrollo inicial de un sistema de Inteligencia Artificial. No implementa un modelo real: su propósito es representar la estructura básica de un sistema (modelo, inferencia, configuración y documentación) para practicar el control de versiones con Git y la colaboración mediante GitHub.

## Objetivo

Aplicar los comandos fundamentales de Git (`init`, `add`, `commit`, `log`, `diff`, `branch`, `push`, `pull`) y el flujo de trabajo colaborativo en GitHub (ramas, Pull Requests y merge), usando como base la organización de un proyecto de IA.

## Estado del proyecto
Prototipo inicial.


## Componentes

- **Modelo** (`modelo.py`): define el nombre y la versión del modelo simulado.
- **Inferencia** (`inferencia.py`): contiene la función `predecir`, que devuelve una predicción simulada.
- **Configuración** (`config.txt`): parámetros básicos del modelo (nombre, versión y entorno).
- **Documentación** (`arquitectura.txt`): descripción del flujo Cliente → API → Modelo → Respuesta.
